## 012 — Frota

**Status:** `sql_valida` | **Origem:** tester | **Dificuldade:** medio

### Pergunta (tester)

Liste a frota atual. Quero modelo, quilometragem rodada, ano de aquisição, consumo de combustível, consumo médio km/L, lotação.

### Notas de construção

km/L pode ser derivado, filtrar frota ativa

### SQL de referência (rascunho)

```sql
WITH gastos_2025 AS (SELECT g.seq_veiculo, SUM(CAST(COALESCE(g.num_marc_final, 0) AS DECIMAL) - CAST(COALESCE(g.num_marc_inicial, 0) AS DECIMAL)) AS km_rodado, SUM(CASE WHEN COALESCE(g.dsc_tipo_gasto, '') ILIKE '%GASOL%' OR COALESCE(g.dsc_tipo_gasto, '') ILIKE '%DIESEL%' OR COALESCE(g.dsc_tipo_gasto, '') ILIKE '%ETAN%' OR COALESCE(g.dsc_tipo_gasto, '') ILIKE '%GNV%' OR COALESCE(g.dsc_tipo_gasto, '') ILIKE '%ALCO%' THEN CAST(COALESCE(g.num_quant_utilizada, 0) AS DECIMAL) ELSE CAST(0 AS DECIMAL) END) AS litros_consumidos FROM frota_gastoFrota g WHERE g.ano_referencia = 2025 AND CAST(g.cod_orgao AS INTEGER) IN (2, 4, 5) GROUP BY g.seq_veiculo), unidades_2025 AS (SELECT u.seq_unidade, u.seq_orgao, MAX(u.dsc_unidade) AS dsc_unidade, MAX(u.dsc_subunidade) AS dsc_subunidade FROM orgao_orgaoUnidade u WHERE u.ano_referencia = 2025 GROUP BY u.seq_unidade, u.seq_orgao) SELECT f.dsc_modelo AS modelo, CAST(f.num_anofabricacao AS INTEGER) AS ano_aquisicao, (COALESCE(u.dsc_unidade, '') || CASE WHEN COALESCE(u.dsc_subunidade, '') <> '' THEN ' - ' || u.dsc_subunidade ELSE '' END) AS lotacao, CAST(g.km_rodado AS DECIMAL) AS quilometragem_rodada, CAST(g.litros_consumidos AS DECIMAL) AS consumo_combustivel_litros, CAST(g.km_rodado AS DECIMAL) / NULLIF(CAST(g.litros_consumidos AS DECIMAL), 0) AS consumo_medio_km_por_litro FROM gastos_2025 g JOIN frota_frota f ON g.seq_veiculo = f.seq_veiculo LEFT JOIN unidades_2025 u ON f.seq_unidade = u.seq_unidade AND f.seq_orgao = u.seq_orgao WHERE COALESCE(f.dsc_marca, '') NOT ILIKE '%DIVERSOS%' AND COALESCE(f.dsc_num_placa, '') NOT IN ('-1', 'NÃO INFORMADO') ORDER BY f.dsc_modelo LIMIT 50;
```

## 014 — Calculo Fiscal

**Status:** `sql_valida` | **Origem:** tester | **Dificuldade:** dificil

### Pergunta (tester)

Quero saber como está a saúde financeira e orçamentária da prefeitura de Caeté?

### Notas de construção

ISF-M e indicadores SIF-Caeté, resposta pode ser multi-indicador

### SQL de referência (rascunho)

```sql
WITH receita_corrente AS ( SELECT SUM(CAST(vlr_realizadoateperiodo AS DECIMAL)) AS total_receita_corrente FROM receita_receita WHERE ano_referencia = 2025 AND dsc_cateconomica ILIKE '%Corrente%' ), despesa_corrente AS ( SELECT SUM(CAST(vlr_liquidado AS DECIMAL)) AS total_despesa_corrente FROM despesa_despesa WHERE ano_referencia = 2025 AND dsc_naturezadespesa ILIKE '3%' ), despesa_saude AS ( SELECT SUM(CAST(vlr_liquidado AS DECIMAL)) AS total_despesa_saude FROM saude_saude WHERE ano_referencia = 2025 ), receita_impostos_transf AS ( SELECT SUM(CAST(vlr_realizadoateperiodo AS DECIMAL)) AS total_receita_impostos_transf FROM receita_receita WHERE ano_referencia = 2025 AND (dsc_especie ILIKE '%Imposto%' OR dsc_origem ILIKE '%Transfer%') ) SELECT CAST(r.total_receita_corrente AS DOUBLE) / NULLIF(CAST(d.total_despesa_corrente AS DOUBLE), 0) AS isf_m, (CAST(ds.total_despesa_saude AS DOUBLE) / NULLIF(CAST(rit.total_receita_impostos_transf AS DOUBLE), 0)) * 100 AS ies_c FROM receita_corrente r CROSS JOIN despesa_corrente d CROSS JOIN despesa_saude ds CROSS JOIN receita_impostos_transf rit;
```
