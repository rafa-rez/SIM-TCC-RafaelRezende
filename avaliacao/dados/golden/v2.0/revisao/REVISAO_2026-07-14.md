## 010 — RH/Folha

**Status:** `sql_valida` | **Origem:** tester | **Dificuldade:** dificil

### Pergunta (tester)

Liste os 20 maiores salários de servidores da Prefeitura. Quero nome, cargo, salário, benefícios, data de admissão, lotação. Faça a lista pedida para os anos de 2024 e 2025.

### Notas de construção

Campos benefícios/admissão podem não existir no SICOM — documentar lacuna

### SQL de referência (rascunho)

```sql
WITH remuneracao_filtrada AS (
  SELECT
    r.ano_referencia,
    r.seq_dim_pessoa,
    MAX(CAST(r.vlr_rmn_liquida AS DECIMAL)) AS salario_maximo,
    MAX(CAST(r.vlr_descontos AS DECIMAL)) AS beneficios,
    MAX(r.dsc_cargo) AS cargo,
    MAX(r.seq_dat_ingresso_cargo) AS data_admissao,
    MAX(r.dsc_lotacao) AS lotacao
  FROM remuneracao_municipio r
  WHERE r.ano_referencia IN (2024, 2025)
    AND r.dsc_sit_serv_pens ILIKE '%Ativo%'
  GROUP BY r.ano_referencia, r.seq_dim_pessoa
),
servidores_nome AS (
  SELECT
    p.seq_dim_pessoa,
    TRIM(p.nom_pessoa) AS nome
  FROM pessoa_municipio p
  WHERE COALESCE(p.nom_pessoa, '') NOT ILIKE '%NAO INFORMADO%'
),
ranking_salarios AS (
  SELECT
    rf.ano_referencia,
    sn.nome,
    rf.cargo,
    rf.salario_maximo AS salario,
    rf.beneficios,
    rf.data_admissao,
    rf.lotacao,
    ROW_NUMBER() OVER (PARTITION BY rf.ano_referencia ORDER BY rf.salario_maximo DESC) AS rn
  FROM remuneracao_filtrada rf
  JOIN servidores_nome sn ON rf.seq_dim_pessoa = sn.seq_dim_pessoa
)
SELECT
  ano_referencia,
  nome,
  cargo,
  salario,
  beneficios,
  data_admissao,
  lotacao
FROM ranking_salarios
WHERE rn <= 20
ORDER BY ano_referencia, salario DESC;
```

## 011 — Licitacoes/Cruzamento

**Status:** `sql_valida` | **Origem:** tester | **Dificuldade:** dificil

### Pergunta (tester)

Mostre as 10 maiores licitações/contratos por ano (23,24 e 25), monte uma tabela conciliando os dados enviados de licitação e contrato (caso forem os mesmos), onde mostra a data da licitação, a data do contrato, o nome do vencedor/contratante, o objeto, o valor , o número da licitação e o número do contrato.

### Notas de construção

Cruzamento licitacao + contrato, anti-duplicata de itens

### SQL de referência (rascunho)

```sql
WITH licitacoes_agg AS (
  SELECT
    l.ano_referencia,
    l.num_processo AS num_licitacao,
    l.num_ano_processo AS ano_licitacao,
    l.dat_abert_proc_adm AS data_licitacao,
    SUM(CAST(h.vlr_global AS DECIMAL)) AS valor_licitacao,
    MAX(TRIM(h.nom_vencedor)) AS nome_vencedor,
    MAX(TRIM(l.dsc_objeto_licitacao)) AS objeto_licitacao
  FROM licitacao_licitacao l
  LEFT JOIN licitacao_homologLicitacao h
    ON l.seq_licitacao = h.seq_licitacao
    AND l.ano_referencia = h.ano_referencia
  WHERE l.ano_referencia IN (2023, 2024, 2025)
  GROUP BY l.ano_referencia, l.num_processo, l.num_ano_processo, l.dat_abert_proc_adm
),
contratos_agg AS (
  SELECT
    c.ano_referencia,
    c.num_contrato,
    c.num_ano_contrato,
    c.dat_assinatura AS data_contrato,
    c.vlr_contrato AS valor_contrato,
    MAX(TRIM(cc.dsc_nome_credor)) AS nome_contratante,
    MAX(TRIM(c.dsc_objetocontrato)) AS objeto_contrato,
    c.num_anoexercicio AS ano_licitacao_contrato,
    c.seq_licitacao,
    c.num_contrato AS num_contrato_contrato
  FROM contrato_contratos c
  LEFT JOIN contrato_contContrato cc
    ON c.seq_contrato = cc.seq_contrato
    AND c.ano_referencia = cc.ano_referencia
  WHERE c.ano_referencia IN (2023, 2024, 2025)
  GROUP BY c.ano_referencia, c.num_contrato, c.num_ano_contrato, c.dat_assinatura, c.vlr_contrato, c.num_anoexercicio, c.seq_licitacao
),
conciliacao AS (
  SELECT
    COALESCE(l.ano_referencia, c.ano_referencia) AS ano_referencia,
    l.num_licitacao,
    l.ano_licitacao,
    l.data_licitacao,
    c.num_contrato,
    c.num_ano_contrato,
    c.data_contrato,
    COALESCE(l.nome_vencedor, c.nome_contratante) AS nome,
    COALESCE(l.objeto_licitacao, c.objeto_contrato) AS objeto,
    COALESCE(l.valor_licitacao, 0) AS valor_licitacao,
    COALESCE(c.valor_contrato, 0) AS valor_contrato,
    GREATEST(COALESCE(l.valor_licitacao, 0), COALESCE(c.valor_contrato, 0)) AS valor
  FROM licitacoes_agg l
  FULL OUTER JOIN contratos_agg c
    ON l.num_licitacao = c.seq_licitacao
    AND l.ano_referencia = c.ano_referencia
)
SELECT
  ano_referencia,
  num_licitacao,
  data_licitacao,
  num_contrato,
  data_contrato,
  nome,
  objeto,
  valor
FROM (
  SELECT
    ano_referencia,
    num_licitacao,
    data_licitacao,
    num_contrato,
    data_contrato,
    nome,
    objeto,
    valor,
    ROW_NUMBER() OVER (PARTITION BY ano_referencia ORDER BY valor DESC) AS rn
  FROM conciliacao
) t
WHERE rn <= 10
ORDER BY ano_referencia, valor DESC;
```

## 014 — Calculo Fiscal

**Status:** `sql_valida` | **Origem:** tester | **Dificuldade:** dificil

### Pergunta (tester)

Quero saber como está a saúde financeira e orçamentária da prefeitura de Caeté?

### Notas de construção

ISF-M e indicadores SIF-Caeté, resposta pode ser multi-indicador

### SQL de referência (rascunho)

```sql
WITH receita_corrente AS ( SELECT SUM(CAST(vlr_realizadoateperiodo AS DECIMAL)) AS total_receita_corrente FROM receita_receita WHERE ano_referencia = 2025 AND dsc_cateconomica ILIKE '%Corrente%' ), despesa_corrente AS ( SELECT SUM(CAST(vlr_liquidado AS DECIMAL)) AS total_despesa_corrente FROM despesa_despesa WHERE ano_referencia = 2025 AND dsc_naturezadespesa ILIKE '3%' ), despesa_saude AS ( SELECT SUM(CAST(vlr_liquidado AS DECIMAL)) AS total_despesa_saude FROM saude_saude WHERE ano_referencia = 2025 ), receita_impostos_transf AS ( SELECT SUM(CAST(vlr_realizadoateperiodo AS DECIMAL)) AS total_receita_impostos_transf FROM receita_receita WHERE ano_referencia = 2025 AND (dsc_especie ILIKE '%Imposto%' OR dsc_origem ILIKE '%Transfer%') ) SELECT CAST(r.total_receita_corrente AS DOUBLE) / NULLIF(CAST(d.total_despesa_corrente AS DOUBLE), 0) AS isf_m, (CAST(ds.total_despesa_saude AS DOUBLE) / NULLIF(CAST(rit.total_receita_impostos_transf AS DOUBLE), 0)) * 100 AS ies_c FROM receita_corrente r CROSS JOIN despesa_corrente d CROSS JOIN despesa_saude ds CROSS JOIN receita_impostos_transf rit;
```
